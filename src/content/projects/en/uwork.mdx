## 🙋🏻‍♂️ My role in the project

I played a key role as a frontend developer and UX/UI designer, participating in the following areas:

- **Planning, analysis, and design**: I collaborated in defining project timelines and phases, as well as analyzing client requirements and scoping. This ensured the project met the expectations and needs of the end user.
- **User interface design**: I worked with the team using Figma to create mockups and prototypes of the screens, focusing on usability and user experience. This enabled more efficient programming and a friendly interface.
- **Frontend programming**: I developed key components and screens of the application, implementing information rendering logic, form validations, and data submission. My work ensured a smooth and responsive interaction for users.
- **Deployment**: I participated in automating the deployment process using GitHub Actions and AWS, speeding up the release of new features and fixes.

## ✨ Project importance

**Uwork** is an important project because it addresses a global challenge: the difficulty many people face in finding jobs that match their skills and needs. This application not only connects candidates with employers but also optimizes the search process, saving time and resources for both candidates and companies.

## 🎇 Business impact

**Uwork** can help users and the job market in the following ways:

- **Facilitates job searching**: Offers a centralized platform where candidates can find opportunities that match their profile.
- **Optimizes processes**: Reduces the time and effort candidates and employers invest in the hiring process.
- **Improves user experience**: An intuitive and personalized interface increases user satisfaction and encourages continued use of the platform.
