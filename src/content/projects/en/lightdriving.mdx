## 🙋🏻‍♂️ My role in the project

I played a key role as a web developer and UX/UI designer, participating in the following areas:

- **User interface design**: I collaborated in creating mockups and prototypes, focusing on designing an intuitive and visually appealing interface. I worked on elements such as button placement, navigation flows, and map integration to ensure a smooth user experience.
- **Frontend programming**: I developed several screens of the application, implementing client-side logic with technologies such as Laravel and CSS. I integrated the Google Maps API to show taxi locations in real time and optimize the user experience. I also worked on dynamic content rendering and route management for efficient navigation.

## ✨ Project importance

**LightDriving** is an important project because it addresses two key issues in Latin America: insecurity in public transportation and the lack of reliable and affordable transportation options. This application not only offers a safe and economical alternative for users but also generates job opportunities for drivers, contributing to the local economy.

## 🎇 Impact on users

**LightDriving** can help users and drivers in the following ways:

- **Safety**: Offers a reliable and traceable transportation service in real time, reducing the risks associated with traditional public transportation.
- **Time savings**: Speeds up the process of finding and picking up a taxi, optimizing travel time.
- **Ease of use**: An intuitive interface and features such as map integration make the experience simple and pleasant.
- **Job opportunities**: Drivers can register and work on the platform, generating income and expanding transportation availability.
