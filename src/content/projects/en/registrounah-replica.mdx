## 🙋🏻‍♂️ My role in the project

I played an integral role as a frontend programmer and UX/UI designer, participating in the following areas:

- **User interface design**: I collaborated in creating mockups and prototypes using Figma, focusing on designing an intuitive, easy-to-use, and visually appealing interface. I worked on elements such as menu layout, buttons, and navigation flows to ensure a smooth and efficient user experience.
- **Frontend programming**: I developed the views and application behavior using technologies such as **Vanilla JavaScript**, **Bootstrap**, and **HTML**. I also implemented server-side logic with **PHP** for session handling and database interaction. I focused on writing clean, organized, and maintainable code, following good development practices.

## ✨ Project importance

This project is important because, although it is a replica, it addresses a real and complex problem: the management of university processes in a large-scale institution such as UNAH. Developing this application allowed us to put into practice technical skills (design, programming, database management) and agile methodologies such as Scrum, which strengthened our ability to work as a team and manage large-scale projects.

## 🎇 Impact on users

The **UNAH Registration** replica offers a solution that can benefit users in the following ways:

- **Process simplification**: Facilitates admissions and enrollment management, reducing the time and effort required for both students and administrative staff.
- **Centralized access**: Provides a unified system where students, teachers, and administrators can manage their tasks efficiently.
- **Intuitive interface**: A well-designed and easy-to-use interface improves the user experience and reduces the learning curve.
